# Experimental direct native transport

The preserved API MHTML gives the packet field ordering, optional addresses and response semantics, escaping relation, checksum placement and big-endian multi-byte convention. Six numerical table embeds are Google Sheets placeholders in the capture; the saved HTML does not contain those table cells. The control-byte values, basic flag bits and one's-complement sum are cross-checked against https://github.com/artificial-intelligence-class/spherov2.py/blob/main/spherov2/controls/v2.py and helper.py. The codec independently implements these semantics. Extended/reserved flags are rejected rather than silently parsed incorrectly. Limit of 4096 decoded bytes is a host safety bound, not a firmware limit.

Original MIX libCore.so (all four bundled ABIs) contains the service UUID 00010001-574f-4f20-5370-6865726f2121 and characteristic 00010002-574f-4f20-5370-6865726f2121. Other Sphero devices use this pair for API V2 (https://github.com/trflorian/sphero_mini_win/blob/master/sphero_mini.py). Presence in a multi-product library does not prove SD01 applicability. Verify against the actual ring GATT inventory.

Select Experimental native RGB mode before selecting a ring. The path checks for the expected service, characteristic, acknowledged-write property and notification/indication CCCD; subscribes, sends only the APK-derived volatile enable-tap command, and waits for a matching successful response. It does not send an unlock sequence, firmware writes, wake commands or palette modifications. If the device requires additional initialization, this attempt can fail. A 20-second deadline closes incomplete connections. Raw RGB/confidence/classification/intensity are displayed; classified IDs 0..11 map directly to pad indices for this experimental mode only. Fixed playback velocity is deliberate: tap intensity scale is not yet known. Unknown classifications never trigger a pad. This does not teach the ring new colors. MIDI mode and read-only GATT inventory remain available.

Tests cover known command bytes, fragmented escapes, addressed replies, escaped checksum, invalid checksum/escape/length, oversized-frame recovery, multiple frames, response correlation and malformed tap events. No physical test has been performed. Confirm handshake, tap delivery, classification IDs and disconnect behavior on SD01 before promoting to stable. Native writes currently require PROPERTY_WRITE rather than WRITE_NO_RESPONSE; additional ring variants remain unsupported.
